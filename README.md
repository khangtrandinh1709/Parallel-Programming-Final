**Cách thức chạy code trên Google Colab**
- Bước 1: Load file notebook lên Google Colab
- Bước 2: Bật GPU T4 trên Colab, bằng cách chọn Runtime -> Change runtime type -> Chọn T4 GPU
- Bước 3: Ở bên trái màn hình, chọn tab Files, và tạo các thư mục: dataset, HostANN, Basic_GPU, ImproveGPU, ImproveGPU_1
- Bước 4: Tải lên Colab tất cả file code, đính kèm trong thư mục Code. Để tải code lên theo đúng thư mục. Ví dụ để load tất cả code trong file HostANN, rê chuột vào thư mục HostANN trên Colab, bấm vào dấu 3 chấm, chọn Upload. Ở màn hình Upload, chọn thư mục tương ứng trong thư mục Code, và upload toàn bộ file trong thư mục đó.
- Bước 5: Chạy toàn bộ code bằng cách chọn Runtime -> Run all. Thời gian chạy code khoảng 10 phút.
